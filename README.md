# for-ai-website

ChatGPT が小さな Web サイトを作り、レビューと改善を繰り返していくための公開リポジトリです。

## 現在のサイト: ONE

「今日やる一つだけ」を決めて、短い集中スプリントを始めるための小さな Web アプリです。

### できること

- 10 / 25 / 50 分の集中タイマー
- 1〜180分の整数を入力して自由なタイマー時間を設定
- 選択中の自由設定時間も既存のタイマー状態として保存し、再読み込み後やバックアップ復元後に利用
- タイマー途中の状態を保存し、再読み込み後も続きから再開
- 開始・一時停止・完了・記録後の状態を画面上で明確に表示
- タイマー完了時はページタイトルでも完了を通知
- 完了音は初期OFF。ユーザーが明示的にONにした場合だけ、0:00到達時にブラウザ内で生成した短い2音を再生
- 完了音をONにしたときは短い試聴音を鳴らし、ブラウザが音声再生を許可できない場合は画面上で案内
- 表示テーマは「自動 / ライト / ダーク」から選択でき、自動では端末のライト・ダーク設定に追従
- 明示的に選んだライト / ダークはOS設定より優先し、同じブラウザの別タブにも反映
- `Space` で開始 / 一時停止、`F` で集中表示、`Escape` で集中表示を解除
- タスク入力中は `⌘/Ctrl + Enter` で開始 / 一時停止
- 文字入力中やボタン操作中、IME変換中はグローバルショートカットを発火させない
- 0:00まで完了した集中だけを1回ずつ記録
- 未記録の完了状態も再読み込み後に復元し、二重記録を防止
- 未記録の完了がある間は次の開始・リセット・時間変更をロックし、「記録する」か「記録せず破棄する」を明示的に選択
- 同じブラウザで複数タブを開いても、同じ完了を別タブから重ねて処理しにくいようセッション単位で照合
- 別タブでリセット・記録・破棄された古いタイマー状態からの再開を防止
- 累計と日次履歴は記録直前に保存値を読み直し、別タブの更新を上書きしにくくする
- 日付をまたいで後から記録しても、実際にタイマーが完了した日の回数として保存
- 「今日」「今週」「連続日数」「累計」の進捗を表示
- 今週の回数は月曜日から今日までの完了数を既存履歴から算出
- 連続日数は今日が未実施なら昨日までの連続を保持し、今日1回記録すれば継続。保存履歴90日すべてが連続する場合は `90+` と表示
- 直近 7 日の集中回数を棒で可視化
- 直近 30 日の集中を曜日に沿ったアクティビティマップで表示し、30日合計と活動日数も算出
- 最大 90 日分の日次履歴を端末内に保存
- 累計・日次履歴・選択中のタイマー時間をJSONへバックアップし、別のブラウザや端末で復元
- 復元JSONは100KB以下・既知キーのみ・正しい日付/回数/1〜180分のタイマー値だけを受け付け、矛盾した記録は拒否
- 復元はタイマーが完全に停止しているときだけ許可し、既存記録を置き換える直前に内容を確認
- 復元直前の累計・日次履歴・タイマー設定を端末内へ1世代だけ退避し、復元後の記録が変わっていない間は「直前の復元を取り消す」で戻せる
- 取り消し前後も保存結果を確認し、不一致があれば可能な範囲で直前の状態へ戻す
- 「この端末のデータを削除」から2段階確認を経て、ONEがブラウザ内に保存したタスク・タイマー・記録・設定・復元用データを初期化
- 端末データ削除時は同じブラウザの別タブにもリセットを通知し、古いタブが削除前の状態を再保存しにくくする
- 「今日やる一つ」は日付付きで保存し、翌日に切り替わると前日のタスクを自動で持ち越さない
- タブを開きっぱなしで日付をまたいだ場合も、画面へ戻った時点で「今日」とタスクの日付を同期
- 進行中・一時停止中・未記録の集中がある場合は、その1回が終わるまでタスクを保持
- タスクとタイマーだけを大きく表示する集中表示モード
- 集中表示は `Escape` キーでも解除可能で、タイマー完了時は記録操作を見せるため通常表示へ戻る
- モバイル表示に対応

### プライバシーと構成

- 静的 HTML / CSS / JavaScript のみ
- ビルド不要、外部依存なし
- タスク、タイマー状態、集中回数、タブ間調停用のランダムなセッションID、完了音ON/OFF、表示テーマ設定は `localStorage` にだけ保存
- 自由設定時間は既存のタイマー状態に含めて保存し、同じ情報を別キーへ二重保存しない
- 完了音は外部音源を読み込まず Web Audio でその場で生成し、通知権限やマイク権限を要求しない
- 完了音と表示テーマは端末ごとのUI設定として扱い、JSONバックアップには含めない
- 表示テーマは `system / light / dark` の3値だけを受け付け、壊れた保存値は自動設定として扱う
- 選択済みテーマはCSSより前にローカルで復元し、ページ表示時のテーマ切替によるちらつきを抑える
- 「今週」「連続日数」「直近30日マップ」は保存済みの日次履歴から都度計算し、新しい追跡データは保存しない
- 復元取り消し用には、復元直前の累計・日次履歴・タイマー設定だけを `localStorage` に1世代保存
- タブ間調停用IDは個人情報や認証情報ではなく、同じブラウザ内で1回の集中を区別するためだけに使用
- バックアップファイルと復元取り消し用データにはタスク本文・実行中タイマー・タブ間セッションIDを含めない
- バックアップの書き出し・読み込みもブラウザ内だけで完結し、サーバーへ送信しない
- 端末データ削除は `localStorage.clear()` を使わず、ONEが使用している既知の保存キーだけを削除する
- すでにダウンロードしたJSONバックアップはブラウザ外のファイルなので、端末データ削除では消さない
- タスク本文の履歴は残さず、その日の入力内容だけを保存
- 外部 API・解析ツール・Cookie なし
- Content Security Policy で外部通信を禁止
- ユーザー由来データを `innerHTML` へ挿入しない
- カウントダウン本体を live region にせず、状態変化だけを読み上げる設計
- GitHub Actions で全ローカルJavaScriptの構文、CSP、危険な DOM / コード実行 / 通信 API、JavaScriptの読み込み順、描画前テーマ復元の順序、タイマーのアクセシビリティ設定、自由設定タイマー・完了音・表示テーマ・端末データ削除の初期状態、ONEの全保存キーが削除対象に含まれること、代表的な秘密情報パターンをチェック

`index.html` をブラウザで開くだけで動きます。

## リポジトリ方針

- 公開リポジトリに置ける情報だけを扱います。
- 秘密鍵、API キー、個人情報などの機密情報はコミットしません。
- 原則として変更は Pull Request 経由で追加します。
- 変更を作ったら、差分をレビューしてから Pull Request を作ります。
